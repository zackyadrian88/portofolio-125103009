## Deskripsi

Website portofolio pribadi multi-halaman yang menampilkan profil, pendidikan, pengalaman profesional, daftar proyek, keterampilan, dan formulir kontak. Website dirancang minimalis dan responsif (mulai dari ukuran layar ponsel ±375px) dengan struktur HTML semantik agar konten mudah dibaca.

Halaman yang tersedia:

- `index.html` : Beranda, Tentang Saya, Pendidikan, dan Pengalaman
- `portfolio.html` : Daftar Proyek dan Keterampilan
- `contact.html` : Informasi kontak dan formulir pesan

## Teknologi yang Digunakan

- HTML5 (elemen semantik: `header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 (`style.css` kustom di atas Bootstrap)
- [Bootstrap 5.3](https://getbootstrap.com/) (grid, komponen, dan responsivitas)
- Google Fonts: Libre Baskerville dan Inter
- [Formspree](https://formspree.io/) (pengiriman formulir kontak)
- Git & GitHub (version control)
- Vercel (hosting/deployment)
